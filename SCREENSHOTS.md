# Screenshot capture list

Every image in these docs has a named slot in `lib/screenshot-slots.json` (its alt text and the file names it may have) and is placed with `<Screenshot slot="…" />`. Until an image is imported, the page shows a marked placeholder. This file is the capture list for the screenshot session. **All 45 slots are captured**, from the Example Corp capture of Pi Durable Platform **v0.1.1** (product commit `900d610`) in `pdp-assets` (its `screenshots/MANIFEST.md` lists each file and the display-only edits). The alt texts in the slots file were checked against those images; the last column below copies them. Check each again after a retake.

## Rules

- **Only a fictional demo instance, never a real install.** Organisation: **Example Corp**, domain `example.com`, the platform at `https://agents.example.com` (any loopback address in the capture environment; the URLs the docs mention use `agents.example.com`), `ORG_NAME=Example Corp`, `INSTANCE_NAME=Example Corp Agents`. Never show a real person, organisation, host, key, token, client ID or provider account.
- **Personas** (all fictional):
  - **Priya Shah**, `priya.shah@example.com`, platform admin
  - **Taylor Brooks**, `taylor.brooks@example.com`, platform auditor
  - **Sam Ortiz**, `sam.ortiz@example.com`, owner of **Support** (`support`), editor of **Data Platform** (`data-platform`), with a personal workspace
  - **Riley Chen**, `riley.chen@example.com`, owner of Data Platform
  - **Jordan Lee**, `jordan.lee@example.com`, member of Support, in the group `agents-users`
  - **Alex Rivera** (Support admin), **Morgan Diaz** (Support editor), **Casey Moore** (suspended)
- **Configuration**: agents on fake model providers (an OpenAI-compatible capture server on `example.com` names, models `general-large` and `general-small` with prices), MCP servers **Company wiki** and **Calendar** (platform) and **Ticket search** (Support) as small capture servers, service accounts **helpdesk-chat** (editor) and **reports-bot** (member), templates **Helpdesk triage** (Support, published, 3 versions), **Release notes writer** (Data Platform, pending), and the platform's **Assistant**. The OAuth app **Example Corp Chat** is a metadata document served by a capture server. No real model provider or third-party account.
- **Launcher**: `local` is fine for capture (loopback `APP_URL`); never show development personas: sign in with a fake OIDC provider so names and emails match the personas.
- **Size**: PNG, **1440×900** (device scale factor 1), light theme, sidebar expanded. Pin the clock in the seed so timestamps don't churn.
- **Secrets**: any key or token shown must be a fake value (`pdp_0000…`, `pdp_sa_0000…`) before capture.
- **File name**: the slot name, `<slot>.png`, in `../pdp-assets/screenshots/`, then:

  ```sh
  SCREENSHOTS_DIR=../pdp-assets/screenshots npm run screenshots
  npm run screenshots:check
  ```

- A slot with `"hold"` in the slots file is skipped by the import; none is held now.
